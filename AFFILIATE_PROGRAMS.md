# Affiliate Program Integration Reference

This reference summarizes affiliate networks under consideration for Brand Janra, including API access, documentation, shipping scope, and onboarding notes.

| Network | API Access | API Docs Link | Shipping Scope | Notes |
| --- | --- | --- | --- | --- |
| **CJ Affiliate (Commission Junction)** | ✔️ Product Catalog API, Link Search API | [CJ Developer Portal](https://developers.cj.com/) | Merchant-specific; many global brands ship to India | Requires approval per advertiser |
| **Impact.com** | ✔️ REST APIs for offers, reporting, product feeds | [Impact API Docs](https://developer.impact.com/) | Merchant-specific; includes global brands like iHerb, Lenovo | Strong automation support |
| **ShareASale** | ✔️ Merchant, transaction, product feed APIs | [ShareASale API Docs](https://account.shareasale.com/a-api.cfm) | Merchant-specific; some US/EU merchants ship to India | Requires merchant approval |
| **Awin** | ✔️ Product Feed API, reporting | [Awin Product Feed Docs](https://success.awin.com/s/article/How-do-I-access-advertiser-s-product-data-in-real-time-Awin-Product-Finder?language=en_US) | Merchant-specific; UK/EU brands, some ship worldwide | Already in the open tab |
| **ClickBank** | ✔️ APIs for product listings, reporting | [ClickBank API Docs](https://www.bing.com/search?q=%22https%3A%2F%2Fsupport.clickbank.com%2Fhc%2Fen-us%2Farticles%2F360015568091-ClickBank-API%22) | Mostly digital products; some supplement vendors ship to India | Easy entry, digital focus |
| **PartnerStack** | ✔️ APIs for SaaS affiliate programs | [PartnerStack API Docs](https://docs.partnerstack.com/) | SaaS products (no shipping needed) | Recurring commissions |
| **Rakuten Advertising** | ✔️ APIs for reporting, product feeds | [Rakuten API Docs](https://developers.rakutenmarketing.com/) | Merchant-specific; global brands, some ship to India | Strong in fashion/electronics |
| **TradeDoubler** | ✔️ APIs for product feeds | [TradeDoubler API Docs](https://developer.tradedoubler.com/) | EU merchants; some ship worldwide | Focus on EU brands |

## References

The links in the table above point to the respective network documentation or reference material supplied for this comparison.
